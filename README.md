# SnnuAutoLogin · 陕师大校园网自动登录

插上网线就不用管了。这个程序常驻系统托盘，发现校园网没认证就自动登录；半夜被踢下线，它也会自己重连。

写给陕师大的同学用。Windows 10/11 x64，不需要管理员权限，不用装 Python 或任何运行环境，单个 exe 拷走就能跑。

## 先说清楚它替你做了什么

在陕师大上网，网卡连上了只是第一步，还得去门户（202.117.144.205:8605）输学号密码认证，断电重连、换设备、会话过期之后都要再来一遍。这个程序就是替你盯着这件事：

- 开机自启，登录 Windows 后几秒内完成首次检测
- 插网线、切 WiFi 时自动检测，需要认证就自动登录
- 在线期间每 60 秒心跳一次，被踢下线自动重连
- 挂机久了会出现一种烦人的状态：网卡显示已连接，门户也说在线，但网页就是打不开，Windows 网络图标变成地球。这是运营商出口的会话被挂起了，门户在说谎。程序每 2 分钟探测一次外网，连续发现这种情况就自动下线重登，一般 4~6 分钟内恢复
- 在家庭 WiFi、手机热点上会自动休眠，不会乱发请求，也不会误登录
- 服务类型配错自动提醒：检测到你的账号实际在别的运营商通道在线时，会提示你改正配置
- 密码错误时不硬试，停下来提醒你改；门户要求验证码时暂停并给出"手动登录一次"的指引，恢复后自动接手

## 下载安装

1. 到 [Releases 页面](https://github.com/Solitudesundae/snnu-autologin/releases) 下载 `SnnuAutoLogin.exe`，放到一个你以后不会挪走的目录（自启动记录的是绝对路径）
2. 双击运行，系统托盘出现图标，同时弹出配置窗口
3. 填学号和密码（就是统一身份认证的密码），选你办的运营商，点"保存并检测"

图标变绿就是在线了。装完之后基本可以忘记它的存在。

默认勾选了开机自启动。如果以后想关掉，右键托盘图标就能切换，或者去任务管理器的"启动应用"里禁用。

## 用 WiFi 的同学看这里

大部分同学是 WiFi 上网，说三件事。

**校园 WiFi。** 连上就行，程序会在网络变化后 2 秒开始检测，一般几秒内登录完成。想开机自启也生效的话，确认这个 WiFi 在 Windows 里勾选了"自动连接"，这样开机登录 Windows 后它自己就连上了，程序随后接管。换教学楼、AP 切换、笔记本合盖再开导致的掉线，都会自动重连，不用管。

**宿舍自己的路由器。** 电脑连自己路由器的 WiFi 时，门户同样可达，程序照常工作——但要注意，这时认证的是整个路由器的网络会话：你的电脑登录一次，路由器下所有设备（包括室友的）都能上网，流量都记在你的账号上。几个人共用一个路由器的话，商量好只在一台电脑上装这个程序，别每个人都跑，会互相顶号。

**手机热点、家庭 WiFi。** 程序探测到没有门户就直接休眠，不会登录也不会发请求，切回校园网时自动恢复工作。

## 托盘图标含义

| 图标 | 状态 | 意思 |
|---|---|---|
| 灰色 ! | 离线 | 没网络、非校园网休眠，或出了需要你处理的问题（悬停看原因） |
| 蓝色 ? | 检测中 | 正在判断当前网络状态 |
| 黄色 … | 认证中 | 正在提交登录 |
| 绿色 √ | 在线 | 校园网认证完成，或者当前是家庭网络 |

双击图标打开配置窗口。右键菜单有：立即检测、配置、开机自启开关、打开门户状态页、打开日志目录、退出。

## 常见问题

**提示"账号或密码错误"**
密码就是你在门户网页登录用的那个。注意密码里不能有分号（分号是门户的限制，不是程序的）。另外检查服务类型选没选对：如果你的套餐是移动/电信，别按默认选成联通——选错了不仅登不上，反复失败还会让门户弹出验证码。

**提示"需要验证码"**
门户在多次登录失败后会对你的 IP 开验证码。程序会暂停自动登录（防止越试越锁），气泡提醒你"点击打开登录页手动登录一次"。你输验证码登录成功后，程序最多 5 分钟内自动恢复自动认证，不需要重新保存配置。

**"剩余流量"在哪里看**
自动登录成功时的气泡里会带一句，更详细的去门户状态页右下角的"自助服务主页"看。

**换了密码**
双击托盘图标，输入新密码保存。密码框留空表示沿用之前保存的密码。

**挪动了 exe 的位置**
自启动会失效（它记的是老路径）。重新打开配置窗口保存一次就好。

**杀毒软件或浏览器提示"未知发布者"**
exe 没有买代码签名证书，SmartScreen 提示属正常现象，点"仍要运行"。在意的话可以从源码自己构建，方法在下面。

**怎么彻底卸载**
退出程序，删掉 exe 和 `%APPDATA%\SnnuAutoLogin` 文件夹。注册表只写过一条自启动项，在配置里取消勾选或任务管理器里禁用即可。

## 密码安全吗

密码用 Windows 自带的数据保护（DPAPI，CurrentUser 作用域）加密后存在 `%APPDATA%\SnnuAutoLogin\config.json`，只能在你这台电脑、你这个 Windows 账户下解密。日志里永远不会出现密码，账号也会打码（如 `425***09`）。

有一点要说实话：学校门户本身是 HTTP 明文传输的，这是门户自己的设计，任何登录方式（包括你在浏览器里登录）都一样。所以别把统一身份认证密码在别处复用，这是更重要的事。

## 从源码构建

需要 .NET 8 SDK：

```
dotnet test tests\SnnuAutoLogin.Tests
dotnet publish src\SnnuAutoLogin -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true -o dist
```

49 个单元测试覆盖了响应解析、状态机、重试策略、加密往返和假在线判定。

exe 有 69MB，是因为自包含了 .NET 运行时，对方电脑什么都不用装。想瘦身可以加 `--self-contained false`，产物不到 2MB，但要求目标电脑装过 .NET 8 桌面运行时。

## 已知限制

- 门户开启验证码时（通常因多次失败触发）需要手动登录一次
- 登录接口是逆向门户得到的，学校如果改版，响应关键字可能要跟着改。好在关键字做成了配置项（`config.json` 的 `Keywords` 节），不用改代码
- 只在 Windows 10/11 x64 上测过
