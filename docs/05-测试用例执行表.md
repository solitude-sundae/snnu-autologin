## 三、待用户实测步骤指引

**用例 1 + 8（自动登录/掉线重登，5 分钟）**
1. 双击 `dist\SnnuAutoLogin.exe` → 配置窗填学号/密码（默认联通）→ 保存。
2. 浏览器打开 `http://202.117.144.205:8605/snnuportal/userstatus.jsp` → 点"断开网络"。
3. 观察托盘：变灰 →（≤60s 心跳周期）自动变绿，气泡提示剩余流量。
4. 打开 `%APPDATA%\SnnuAutoLogin\captures\`：应出现 `*_login_page_*.html` 与 `*_login_resp_*.html`，把登录响应原文反馈给开发者以修订 docs/01 §5 关键字词典。

**用例 5（家庭 WiFi）**：连接手机热点 → 托盘应显示"在线（非校园网环境）"且不发起登录。
